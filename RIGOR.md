## Notes

The idea and plan are mine, worked out with an AI in a build document. The implementation
(the dispatcher, host setup, images, templates and scripts) was delegated in full to Claude
Code; I have run it but not read it, hence `unexamined` and `comprehended: no`.

- **quality_reviewed / security_reviewed: ai**: the host setup and network-install scripts were
  put through independent AI security and reversibility reviews before being run as root;
  their findings were fixed.
- **tested: ai**: a stdlib unit test suite covers the dispatcher (board transitions, triage,
  doors, security tiers, gate configuration). The whole pipeline was also run end to end on
  real hardware: tickets through triage, work, review, security and the gate on a small
  small low-power box, and Pi agents on an older one.

It runs my own setup; I am not recommending anyone depend on it, so `vouch` is **neutral**.
